# Лабораторная работа №2 — Список отелей

Govorov Pavel, K3340. Вариант 1.

## Что реализовано

- Регистрация, вход и выход.
- Каталог номеров и страница номера с информацией об отеле, владельце, цене, вместимости и удобствах.
- Создание, изменение и удаление собственных бронирований.
- Отзывы: автор, период проживания, текст, оценка от 1 до 10.
- Заселение и выселение в Django Admin.
- Таблица постояльцев за последний месяц, доступная администратору, с фильтром по отелю.
- CSS-оформление, адаптивная сетка, меню, пагинация, поиск без учёта регистра и фильтры.

Фотографии интерьеров находятся в `static/images/` и используются как иллюстрации. Источники и лицензия: `static/images/SOURCES.md`. Визуальные ориентиры оформления — Locke и The Hoxton; интерфейс сделан на обычном HTML/CSS без дополнительных библиотек.

Используются Django 5.2, Jinja2 и PostgreSQL. Django 3 из старой формулировки задания несовместим с установленным Python 3.14, поэтому использована ветка 5.2. Архитектура и требуемые возможности сохранены. Django Admin использует свой стандартный шаблонизатор; страницы сайта — Jinja2.

## Запуск с нуля

Нужны Python 3.10+ и установленный PostgreSQL 14+.
Команды выполняются из этой папки.

Для поиска кириллицы используется ICU-collation `und-x-icu`, доступная в стандартных сборках PostgreSQL с ICU.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Создайте в PostgreSQL пустую базу `hotel_lab` (через pgAdmin или `createdb -U postgres hotel_lab`). Укажите в `.env` пользователя, пароль и порт вашей БД.

```powershell
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py createsuperuser
.\.venv\Scripts\python.exe manage.py runserver
```

Сайт: <http://127.0.0.1:8000/>. Админ-панель: <http://127.0.0.1:8000/admin/>.

На новом компьютере добавьте отели и номера через Django Admin, а обычного пользователя — через страницу регистрации. В локальной базе для демонстрации подготовлены 6 отелей и 18 номеров: «Невский», «Приморский», «Сосновый Бор», «Петроградский», «Васильевский» и «Репино Парк». Названия, адреса и цены — учебные примеры, не реальные предложения бронирования.

## Проверка

Из папки работы, используя установленный интерпретатор:

```powershell
python manage.py check
python manage.py makemigrations --check --dry-run
```

Для демонстрации зарегистрируйте пользователя, создайте бронь на свободные будущие даты, измените её и откройте страницу подтверждения удаления. Создайте суперпользователя командой `createsuperuser`, откройте Django Admin → «Бронирования». Для заселения укажите статус «Заселён» и фактическую дату; для выселения — статус «Выселен» и обе фактические даты. Таблица постояльцев находится в меню сайта «Постояльцы».
